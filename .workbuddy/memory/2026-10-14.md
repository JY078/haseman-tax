## 报税数据页:统一 Amazon 平台下载报表交互
- 问题:AmazonTaxTables.vue 内部独立实现下载(blob 下载、独立 downloadBusy/downloadError),与 Walmart/TikTok 平台共享的 downloadFile 流程不一致(不与下载记录面板互斥、下载后不刷新下载记录、刷新按钮会被下载禁用)。
- 修改:
  - web/src/views/TaxDataView.vue:向 AmazonTaxTables 传入 `:download-busy` `:download-error` `:download-file` 三个 props。
  - web/src/components/AmazonTaxTables.vue:删除内部 downloadBusy/downloadError 状态与自带的 blob 下载实现,exportReport 改为调用注入的共享 downloadFile('/tax-data/amazon/export', 'export', ...);刷新按钮禁用条件改为仅 `loading`,与其他平台一致;保留 `tab === 'categories'` 时禁用下载按钮的特有逻辑。
- 后端确认:/tax-data/amazon/export (backend/internal/handler/amazon_tax_reports.go) 同样经 deliverTaxFile 写入 TaxDownloadLog(platform=amazon),故前端统一后下载记录/互斥行为与另两平台完全对齐。
- 验证:web 目录 `npm run build` 通过。

## 修复 Amazon 下载报表按钮 hover 样式与其他平台不一致
- 根因:AmazonTaxTables.vue 的 `.export-btn` 只定义了基础样式(深蓝底白字),缺少 hover 规则;鼠标悬停时命中组件内通用 `button:hover { background:#f3f6f9; border-color:#bdcad7; }`,深蓝按钮变浅灰底白字。TaxDataView.vue(Walmart/TikTok)则有 `.export-btn:hover { background:#204e70; }`。
- 修复:在 AmazonTaxTables.vue 的 `.export-btn` 规则后补上相同的 `.export-btn:hover { background:#204e70; }`。
- 验证:`npm run build` 通过。

## 报关单页面样式与交互优化
- 文件:web/src/views/CustomsDeclarationsView.vue
- 弹窗不居中根因:Tailwind v4 preflight 的 `* { margin: 0 }`(author 样式)覆盖浏览器 UA 对 `dialog:modal` 的 `margin: auto`,导致 showModal 弹窗贴顶。修复:dialog 规则显式加 `position:fixed;inset:0;margin:auto`(并加 `overflow:auto` 防内容超 90vh 被裁切)。此坑适用于 web 项目所有用原生 `<dialog>` 的页面。
- 精简灰色小字:删除顶部 hint 整段、表格行内逐条商品小字、"扫描识别/文字提取"小字;保留 header 副标题和合同号 small。
- 删除弹窗内"查看 PDF 提取原文" details 块及对应 details/summary/pre 样式;"下载原文件"按钮从弹窗底部移到标题栏右侧 detail-actions(与"关闭"并排)。
