## Wayfair Listing 标准落地（生成 / 校验 / 评估 / 评审）

用户提供 Wayfair 官方风格运营标准，要求落到本项目。两个决策点已由用户确认：
1. 评估从通用八维切换为 Wayfair 专属 100 分表；
2. 生成端硬约束用代码硬校验 + 修复重试。

### 评分口径（唯一权威）
- Title 20：Core Product / Key Attributes / Key Function / SEO Coverage / US Readability 各 4。
- About This Product 30：Product Value 6、Function 6、Consumer Benefit 5、Use Scenario 4、
  US-Native English 4、Wayfair Compliance 5。
- Features 50：Features 25（3–5 条 / 5–10 words / Feature→Benefit / 信息优先级 / 不重复 各 5）、
  Compliance 15（准确性、不夸大、不空洞、无品牌供应商、无保修配送售后 各 3）、
  Readability 10（Native English 3、Scannability 3、Conciseness 2、Consumer-Friendly 2）。
- 三级扣分：A 类合规 / B 类最佳实践 / C 类美国消费者与 SEO，分值区间见技能文件。
