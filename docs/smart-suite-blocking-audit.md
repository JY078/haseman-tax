# 套图流程阻断检查

## 本次发现及处理

| 路径 | 缺陷 | 处理 |
| --- | --- | --- |
| 文案失败反馈 | 已放宽标题重复校验，但重试反馈仍可用重复标题覆盖真正的长度错误 | 删除禁止重复标题的反馈；保留实际校验原因 |
| 任务错误摘要 | 已接受标题列表位于原因之前，500 字截断后只看到上下文 | 图片身份、具体错误置前，上下文置后 |
| 创意建议 | 非阻断建议仍要求提供 correction，缺字段导致响应修复 | 建议只需定位和问题描述；真正阻断项仍需纠正说明 |
| 多模式构图 | 导演、规划和生图要求逐状态演示/标签，验收却只允许标题副标题 | 全链路允许单个真实控制/细节场景；仅已规划的分面板需要不同动作，不增标签 |
| 画面规划恢复 | 丢弃整批修复之前的有效模块 | 修复仍失败时保留原始可解析模块，交给已有逐模块校验筛选 |
| 画面规划重试 | 最多三轮重新请求，没有携带上次错误 | 单次定向补齐，传入最近错误；每次请求仍有一次结构修复 |

## 验证边界

回归测试覆盖错误摘要、建议无 correction 放行、仅重试缺失模块及错误反馈、供应商失败不能被布局兜底掩盖、多模式提示词一致性。后端全量 Go 测试通过。这些是系统后端测试，模型响应使用测试输入，不代表真实模型或线上完整出图已经通过。

本地真实模型 contract 检查使用数据库配置的模型与服务地址，通过系统适配器发请求。当前返回 HTTP 401；本地数据库没有可回放的线上套图任务。因此没有完成线上任务、真实产品参考图和生图模型的端到端验收，也没有部署。

保留必要阻断：缺少产品参考图、供应商鉴权/网络错误、无法解析或缺失内容、文案上限、事实引用错误、明确无依据主张、结构不完整，以及纠正后仍存在的真实阻断问题。当前不承诺任意模型响应都能出图；不会通过伪造文案、单位或跳过产品真实性校验来放行。
