## 可复用真实测试入口

在 backend 目录用 PowerShell 执行：

```powershell
$env:SMART_SUITE_LIVE='probe'
go test ./internal/handler -run '^TestSmartSuiteLiveCreativeGate$' -count=1 -v
```

`probe` 仅检查配置及最近任务；`contract` 使用明确标注的合成产品方案和注入的问题调用真实模型，验证返工响应契约；`run` 使用数据库中已有快照和真实产品参考，执行创意验收及返工，直到形成最终提示词。可用 `SMART_SUITE_LIVE_TASK` 指定任务 ID。后两种模式会调用付费模型，但不会写入原任务或生成图片。执行后用 `Remove-Item Env:SMART_SUITE_LIVE` 清除开关。

继续真实验收需要：可用的模型访问凭证，以及同一环境可读取的真实套图任务快照和参考图。完整生图和成品视觉验收仍需另行执行。
